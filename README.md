# Pipeline des prospects Mstudio (version publique)

Application web de suivi du pipeline commercial : tableau par étape (glisser-déposer), liste triable, filtres, alertes d'échéance, ajout et modification de comptes, export et import CSV.

Cette version publique est anonymisée : les noms des comptes, des interlocuteurs et de l'équipe, ainsi que le détail des actions et des notes, sont masqués. Les modifications faites dans l'application restent dans le navigateur de la personne qui les fait.
